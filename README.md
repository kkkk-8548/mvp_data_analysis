# Análise de Dados de Energia Renovável no Mundo

Repositório dedicado a realizar um MVP (Minimum Viable Product) para a sprint de 'Análise de Dados e Boas Práticas' do curso de pós-graduação em Ciência de Dados e Analytics na PUC-Rio.
O notebook acima tem documentado todo o processo de discovery, pré-processamento e análise dos dados.

Foi analisado dados de geração de energia renovável mundialmente segmentado por países e continentes desde 1950, no qual foi possível identificar padrões e insights.
